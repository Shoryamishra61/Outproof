# ADR 0012: Fresh reviewed authority pages through the authenticated model host

Render successfully retrieves both reviewed OSM geometries but its connection to Chandigarh Tourism times out (actual ConnectTimeout, 2026-10-10T03:45:38Z). The same official page and unchanged strict normalizer succeeded from Windows. No larger response limit, weaker parser, or invented source data is justified.

The existing protected laptop model proxy now exposes one additional GET operation for the two registered Chandigarh garden IDs. IDs select fixed HTTPS authority URLs; callers cannot supply an upstream URL. Anonymous/wrong credentials are rejected, redirects are refused, bytes are bounded to 1 MiB, source calls are serialized, and upstream failures return 503. Credentials are not forwarded to the authority.

The production API uses this operation when the existing HTTPS model endpoint and backend-only key are configured. It verifies original source identity and a timezone-aware fetch timestamp no older than 30 seconds before applying the unchanged title, locality, fee, hours, pedestrian access, currency and hard-rule checks. Provenance keeps the original authority URL, body hash, actual observation time and explicit relay transport. It never substitutes cached claims after facts change.

This does not establish permanent hosting. Both inference and this narrow source transport depend on the laptop and authenticated temporary tunnel. No domain, subscription or paid hosting was acquired. General India admission/hours coverage remains incomplete; physical trials remain unexecuted.
