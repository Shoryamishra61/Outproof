# DEV Post Plan

## Working title

**I Stopped Asking AI Where to Go. I Made It Prove the Plan First.**

## Hook

Four people can agree they want to go out and still never leave.

One option is too expensive. Another is too far. Someone is vegetarian. Someone needs to be back in 90 minutes. Everyone starts browsing. Nobody decides.

So I built an AI planner that isn't allowed to recommend anything until it proves the outing fits.
